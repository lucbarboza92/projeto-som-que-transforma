# Som que Transforma

Plataforma web desenvolvida como projeto acadêmico para apoiar a presença digital de organizações do terceiro setor.

## Sobre o projeto

O Som que Transforma apresenta uma organização voltada à realização de oficinas de musicalização para crianças e adolescentes, promovendo atividades de ritmo, percepção musical, coral e contato com músicos.

A plataforma busca ampliar a divulgação dos projetos, facilitar o contato com interessados e apresentar possibilidades de participação por meio de doações e voluntariado.

## Funcionalidades

- Navegação entre páginas utilizando JavaScript;
- Apresentação dos projetos sociais;
- Formulário de cadastro com validação de dados;
- Armazenamento de informações com localStorage;
- Layout responsivo;
- Interações e manipulação do DOM;
- Organização modular do código JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Versionamento

O projeto utiliza Git para controle de versão, com organização de branches baseada no GitFlow e utilização de Conventional Commits para padronização do histórico.
