# Som que Transforma

Plataforma web desenvolvida como projeto acadêmico para apoiar a presença digital de organizações do terceiro setor.

## Sobre o projeto

O Som que Transforma apresenta uma organização voltada à realização de oficinas de musicalização para crianças e adolescentes, promovendo atividades de ritmo, percepção musical, coral e contato com músicos.

A plataforma busca ampliar a divulgação dos projetos, facilitar o contato com interessados e apresentar possibilidades de participação por meio de doações e voluntariado.

## Funcionalidades

- Navegação entre páginas utilizando JavaScript;
- Apresentação dos projetos sociais;
- Formulário de cadastro com validação de dados;
- Armazenamento de informações com localStorage;
- Layout responsivo;
- Interações e manipulação do DOM;
- Organização modular do código JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Versionamento

O projeto utiliza Git para controle de versão, com organização de branches baseada no GitFlow e utilização de Conventional Commits para padronização do histórico.

## Execução local

Para executar o projeto localmente:

1. Clone o repositório para o computador:
   `git clone https://github.com/lucbarboza92/projeto-som-que-transforma.git`

2. Acesse a pasta do projeto:
   `cd projeto-som-que-transforma`

3. Abra o projeto no Visual Studio Code:
   `code .`

4. Execute a aplicação abrindo o arquivo `index.html` no navegador ou utilizando a extensão Live Server do Visual Studio Code.

O projeto utiliza HTML5, CSS3 e JavaScript e não necessita de instalação de dependências externas para sua execução.
## Fluxo de versionamento

O desenvolvimento utiliza Git e GitHub com organização baseada em GitFlow. A branch `main` representa a versão estável, a `develop` concentra as alterações integradas durante o desenvolvimento e branches `feature/*` são utilizadas para funcionalidades e ajustes específicos.

As alterações são registradas por meio de commits e enviadas ao GitHub. Issues e milestones auxiliam no acompanhamento das tarefas, enquanto Pull Requests são utilizados para revisar e integrar alterações das branches de feature à `develop`.
